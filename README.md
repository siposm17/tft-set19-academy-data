# TFT Set 19 Academy data

Dataset for a personal TFT Set 19 (Prismatic Tour) learning app. Loaded as a script from jsDelivr:

```html
<script src="https://cdn.jsdelivr.net/gh/siposm17/tft-set19-academy-data@main/data.js"></script>
```

Defines `window.SET19` (overview, keywords, traits, champions, items, emblem recipes, comps). Images are embedded as data URIs.

Data compiled from public PBE previews (Nov 2026), values may change. TFT images belong to Riot Games. This is a non-commercial fan project and is not endorsed by Riot Games.
